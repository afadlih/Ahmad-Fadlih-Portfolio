# Bilingual Content Guide

## Route

```text
/id
/en
```

Language switch mengubah URL. Konten Bahasa Indonesia dan Inggris dapat diindeks sebagai halaman berbeda.

## Bentuk data

```json
{
  "id": "Teks Indonesia",
  "en": "English text"
}
```

## Prinsip

Jangan menerjemahkan kata per kata.

Bahasa Indonesia harus terdengar seperti penjelasan seorang developer Indonesia.

English harus singkat, natural, dan mudah dipahami oleh recruiter atau engineer.

## Nama teknologi

Next.js

## Review

Sebelum published:

- baca teks ID tanpa melihat versi EN;
- baca versi EN sebagai teks mandiri;
- hapus kalimat yang hanya mengulang title;
- pastikan tidak ada klaim yang tidak dapat dibuktikan.
