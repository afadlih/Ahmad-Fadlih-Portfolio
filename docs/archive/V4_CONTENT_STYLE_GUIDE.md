# V4 Content Style Guide

## Bahasa Indonesia

Gunakan kalimat langsung.

Lebih baik:

```text
Saya membangun dashboard untuk memantau status kolam dan kesehatan perangkat.
```

Hindari:

```text
Saya menghadirkan solusi inovatif yang mengoptimalkan ekosistem operasional.
```

## Bahasa Inggris

Gunakan terjemahan natural, bukan terjemahan kata per kata.

Lebih baik:

```text
I built a dashboard for pond status, alarms, and edge-device health.
```

Hindari:

```text
I realize an innovative solution for operational ecosystem optimization.
```

## Urutan penjelasan project

```text
Problem
What was built
My role
How it works
Technical decisions
Testing
Limitations
```

## Klaim

Jangan menulis:

- production-ready jika belum dideploy;
- realtime jika data masih mock;
- AI-powered jika AI hanya bagian kecil;
- fully automated jika masih perlu intervensi manual;
- scalable tanpa hasil uji.

## Istilah

Gunakan AI hanya ketika memang menjelaskan bagian AI.

Gunakan project untuk nama karya. Gunakan proyek hanya jika seluruh dokumen ingin memakai Bahasa Indonesia formal secara konsisten.

## Tanda baca

Hindari em dash. Gunakan titik, koma, titik dua, atau tanda kurung jika memang diperlukan.

## Deep dive

Satu deep dive harus memiliki:

- kebutuhan pengguna;
- alasan fitur;
- pendekatan;
- percobaan awal;
- masalah yang ditemukan;
- iterasi;
- keputusan teknis;
- alasan;
- trade-off;
- pengujian;
- hasil.
