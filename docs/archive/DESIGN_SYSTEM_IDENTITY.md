# Design system identitas Ahmad Fadlih

Palet baru tidak memakai gambar project buatan atau blok hitam placeholder.

- Midnight navy: engineering yang tenang dan dapat dipercaya.
- Cobalt blue: teknologi dan eksekusi produk.
- Teal: monitoring, sistem operasional, dan IoT.
- Warm gold: proses belajar, sertifikat, dan pencapaian manusia.

Tiga aturan tampilan:

1. Teks menjelaskan masalah sebelum teknologi.
2. Gambar hanya tampil ketika bukti asli tersedia.
3. Setiap project menunjukkan status public/private dan tahap pengerjaan dengan jujur.
