# V18 Readability and Product Story Notes

## What changed

- Rewrote hero, selected work, project summary, problem, and outcome copy so it feels easier to read in Bahasa Indonesia and English.
- Increased light-mode contrast for foreground, muted text, borders, and card surfaces.
- Added a visible feature strip to each sticky project card so visitors can understand the feature value before opening the case study.
- Kept code evidence and GitHub file links, but made the labels more natural.
- Preserved the bounded sticky-card deck and responsive fallback from V17.

## Design intent

The surface now follows a product-story pattern:

1. what it does;
2. what problem it removes;
3. what users see immediately;
4. how the flow works;
5. where the code proof lives.

This makes the portfolio easier to scan while keeping the deeper engineering proof available in the project page.
