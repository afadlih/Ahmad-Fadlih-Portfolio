# V27 Calm Blue Layout Audit

V27 replaces the previous warm accent system with a calm blue visual language and reduces empty layout areas across the home page and inner pages.

## Main changes

- One semantic blue palette for light and dark themes.
- No yellow, gold, amber, or warm accent in the active interface.
- Denser and more balanced hero, project, approach, portfolio hub, resume, project detail, and system map layouts.
- Homepage sticky project behavior is disabled so project cards remain predictable on short screens.
- More natural Indonesian and English copy.
- Shared design tokens remain centralized through CSS variables.
- No new runtime dependency.
