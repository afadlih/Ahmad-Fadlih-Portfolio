# V28 Release Notes

## Ringkasan

V28 mengganti layout V27 dengan sistem portfolio yang lebih ringkas dan berbasis bukti.

## Perubahan

- Menghapus sticky project deck dan special layout untuk kartu terakhir.
- Mengubah tiga project utama menjadi grid konsisten.
- Mengubah project pendukung menjadi daftar ringkas.
- Menghapus QuickIntro yang mengulang isi hero dan section berikutnya.
- Mengganti class legacy `simple` dan `purpose` dengan nama semantic.
- Menghapus stylesheet lama dan mempertahankan lima modul V28.
- Menyatukan seluruh warna ke palet biru tenang.
- Menghapus gradient dan warna hangat dari Open Graph image.
- Menambahkan validator theme, featured layout, responsive layout, dan release preflight.
- Memperbarui README, tests, dan package version ke 28.0.0.
