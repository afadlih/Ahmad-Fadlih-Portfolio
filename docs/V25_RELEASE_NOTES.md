# V25 Simple and Clear Portfolio

V25 removes the experimental interface-deck presentation from the homepage and returns the site to a simpler portfolio structure.

## Main changes

- Rebuilt the hero as a straightforward two-column introduction.
- Reduced navigation choices to projects, approach, system map, resume, and contact.
- Simplified featured-project cards so the homepage shows the problem, outcome, main features, and flow without exposing dense source-code paths.
- Grouped supporting projects into products and systems, plus testing and learning.
- Reworked the light and dark palettes with stronger text contrast and quieter surfaces.
- Rewrote Indonesian and English copy using shorter and more natural sentences.
- Preserved detailed case studies, system map, resume pages, evidence, and source-code references.
