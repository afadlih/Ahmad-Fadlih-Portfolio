# Contributing

This is a personal portfolio repository. Changes should preserve traceability and avoid unsupported claims.

## Content workflow

1. Add incomplete content to `src/content/drafts/`.
2. Add media to the appropriate `public/media/` folder.
3. Fill Indonesian and English copy.
4. Set an honest evidence status.
5. Move the item to the public content file only after review.
6. Run `npm run qa:light`.

## Project deep dive workflow

A featured deep dive requires:

- user need;
- implementation approach;
- development iteration;
- technical decision and trade-off;
- validation;
- outcome;
- at least two concrete implementation paths;
- evidence reference;
- limitation and next step.

## Pull request checklist

- no secrets or private data;
- owner-approved generated portraits must keep a documented provenance note and must not be described as an original studio photograph;
- no direct links to private repository files;
- no placeholder marked as verified;
- no em dash-heavy or generic promotional copy;
- `npm run verify` passes.
